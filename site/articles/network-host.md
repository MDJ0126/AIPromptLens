# 네트워크 호스트

## 핵심 구조

네트워크 호스트 → 기본 정의 → 적용 범위와 비교

## 개념 설명

한 프로세스나 참여자가 서버와 로컬 클라이언트 역할을 함께 수행하는 멀티플레이 구성입니다.

## 비교와 선택

전용 서버 구성과 구분합니다. 구체적인 API는 사용하는 네트워크 패키지에 따라 다릅니다.

## 적용 범위

Netcode for GameObjects 2.4을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시
