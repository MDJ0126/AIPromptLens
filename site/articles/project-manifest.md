# 프로젝트 패키지 매니페스트

## 핵심 구조

프로젝트 패키지 매니페스트 → 기본 정의 → 적용 범위와 비교

## 개념 설명

Packages/manifest.json에서 프로젝트의 패키지 의존성을 선언합니다.

## 비교와 선택

패키지 자체의 package.json과 역할이 다릅니다. 패키지 잠금 파일과도 구분합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.
