# 캡슐 콜라이더

## 핵심 구조

캡슐 콜라이더 → 기본 정의 → 적용 범위와 비교

## 개념 설명

반구 두 개와 원통 형태로 물체의 충돌 영역을 근사합니다.

## 비교와 선택

캐릭터 같은 형상에 활용합니다. 축 방향과 높이·반지름을 모델 외형과 구분해서 설정합니다.
