# 애니메이션 파라미터

## 핵심 구조

입력·데이터 → 설정·처리 → 결과 확인

## 개념 설명

애니메이션 제어기에 전달하는 숫자·불리언·트리거 등의 입력입니다.

## 비교와 선택

파라미터 변경 자체와 전환 조건 만족 여부를 구분합니다.

## 적용 범위

Unity 6.0 공식 용어와 문서를 기준으로 설명합니다. 공통 개념인 경우에도 Unreal에서 같은 이름이나 설정을 제공한다고 가정하지 않습니다.

## 도식의 한계

도식은 읽는 순서를 안내합니다. 기술을 실제로 재현한 애니메이션이나 엔진 실행 결과가 아닙니다.

## 요청 예시

애니메이션 파라미터의 데이터와 처리 흐름을 설명하고 파라미터 변경 자체와 전환 조건 만족 여부를 구분합니다.
