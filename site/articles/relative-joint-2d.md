# 2D 상대 조인트

## 핵심 구조

2D 상대 조인트 → 기본 정의 → 적용 범위와 비교

## 개념 설명

두 Rigidbody2D 사이에 설정한 상대 위치와 각도를 유지하도록 구동합니다.

## 비교와 선택

Fixed Joint 2D와 구동 방식 및 설정이 다릅니다. 최대 힘과 토크를 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

2D 상대 조인트의 의미를 설명하고 다음 조건을 구분해 주세요. Fixed Joint 2D와 구동 방식 및 설정이 다릅니다. 최대 힘과 토크를 확인합니다.
