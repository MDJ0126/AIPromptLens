# 타깃 매칭

## 핵심 구조

입력·데이터 → 설정·처리 → 결과 확인

## 개념 설명

애니메이션의 특정 구간에서 신체 부위가 목표 위치에 맞도록 조정합니다.

## 비교와 선택

일반적인 IK와 같은 기능이라고 단정하지 않습니다.

## 적용 범위

Unity 6.0 공식 용어와 문서를 기준으로 설명합니다. 공통 개념인 경우에도 Unreal에서 같은 이름이나 설정을 제공한다고 가정하지 않습니다.

## 도식의 한계

도식은 읽는 순서를 안내합니다. 기술을 실제로 재현한 애니메이션이나 엔진 실행 결과가 아닙니다.

## 요청 예시

타깃 매칭의 데이터와 처리 흐름을 설명하고 일반적인 IK와 같은 기능이라고 단정하지 않습니다.
