# Windows VideoCapture

## 핵심 구조

Windows VideoCapture → 기본 정의 → 적용 범위와 비교

## 개념 설명

지원되는 Windows 장치에서 카메라 영상을 기록하는 Unity API입니다.

## 비교와 선택

일반적인 모든 플랫폼용 게임 녹화 기능이 아닙니다. 장치·카메라·마이크 권한을 확인합니다.
