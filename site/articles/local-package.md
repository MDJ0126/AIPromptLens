# 로컬 패키지

## 핵심 구조

로컬 패키지 → 기본 정의 → 적용 범위와 비교

## 개념 설명

파일 시스템의 경로를 참조하여 프로젝트에 연결하는 패키지입니다.

## 비교와 선택

Packages 폴더에 포함된 임베디드 패키지와 구분합니다. 다른 개발 환경에서도 경로가 유효해야 합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.
