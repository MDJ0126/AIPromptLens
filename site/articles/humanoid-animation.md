# 휴머노이드 애니메이션

## 핵심 구조

휴머노이드 애니메이션 → 기본 정의 → 적용 범위와 비교

## 개념 설명

인체에 대응하는 뼈 매핑을 이용하여 애니메이션을 처리하는 방식입니다.

## 비교와 선택

Generic 리그와 구분합니다. 리타기팅에는 유효한 Avatar 설정이 필요합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

휴머노이드 애니메이션의 의미를 설명하고 다음 조건을 구분해 주세요. Generic 리그와 구분합니다. 리타기팅에는 유효한 Avatar 설정이 필요합니다.
