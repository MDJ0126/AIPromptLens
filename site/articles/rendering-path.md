# 렌더링 경로

## 핵심 구조

렌더링 경로 → 기본 정의 → 적용 범위와 비교

## 개념 설명

파이프라인 안에서 조명과 표면을 계산하는 방식의 선택입니다.

## 비교와 선택

파이프라인 자체와 Forward·Deferred 같은 경로를 구분합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

렌더링 경로의 의미를 설명하고 다음 조건을 구분해 주세요. 파이프라인 자체와 Forward·Deferred 같은 경로를 구분합니다.
