# 스크립팅 백엔드

## 핵심 구조

스크립팅 백엔드 → 기본 정의 → 적용 범위와 비교

## 개념 설명

Unity 스크립트를 실행 가능한 코드로 처리하는 런타임 기술입니다.

## 비교와 선택

Unity 6의 Mono와 IL2CPP를 기준으로 설명합니다. 오래된 .NET 백엔드 안내를 현재 선택지로 제시하지 않습니다.

## 적용 범위
