# 패키지 기능 세트

## 핵심 구조

패키지 기능 세트 → 기본 정의 → 적용 범위와 비교

## 개념 설명

관련 기능을 제공하는 여러 패키지를 묶어 관리하는 단위입니다.

## 비교와 선택

하나의 런타임 컴포넌트가 아닙니다. 필요한 패키지와 버전 호환성을 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

패키지 기능 세트의 의미를 설명하고 다음 조건을 구분해 주세요. 하나의 런타임 컴포넌트가 아닙니다. 필요한 패키지와 버전 호환성을 확인합니다.
