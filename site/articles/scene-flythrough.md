# 씬 플라이스루 모드

## 핵심 구조

씬 플라이스루 모드 → 기본 정의 → 적용 범위와 비교

## 개념 설명

Scene 뷰를 1인칭 이동처럼 탐색하는 에디터 조작 모드입니다.

## 비교와 선택

게임에 자동으로 추가되는 카메라 기능이 아닙니다. 런타임 이동 로직은 별도로 구현합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

씬 플라이스루 모드의 의미를 설명하고 다음 조건을 구분해 주세요. 게임에 자동으로 추가되는 카메라 기능이 아닙니다. 런타임 이동 로직은 별도로 구현합니다.
