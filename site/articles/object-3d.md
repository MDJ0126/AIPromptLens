# 3D 오브젝트

## 핵심 구조

3D 오브젝트 → 기본 정의 → 적용 범위와 비교

## 개념 설명

메시와 변환 등을 이용해 입체적인 게임 요소를 구성합니다.

## 비교와 선택

오브젝트 데이터와 실제로 화면에 그리는 Renderer의 역할을 구분합니다.

## 적용 범위
