# 키 입력

## 핵심 구조

키 입력 → 기본 정의 → 적용 범위와 비교

## 개념 설명

키보드 버튼의 상태를 입력 시스템으로 읽는 구성입니다.

## 비교와 선택

문자 입력과 물리 키 입력을 구분합니다. 한글 입력에는 텍스트 입력 체계를 사용합니다.
