# 텍스처 포맷

## 핵심 구조

텍스처 포맷 → 기본 정의 → 적용 범위와 비교

## 개념 설명

GPU가 텍스처 데이터를 저장하고 해석하는 형식입니다.

## 비교와 선택

원본 이미지 파일 확장자와 런타임 포맷을 구분합니다. 색 채널과 정밀도·압축 지원을 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.
