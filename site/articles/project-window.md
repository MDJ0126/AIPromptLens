# Project 창

## 핵심 구조

Project 창 → 기본 정의 → 적용 범위와 비교

## 개념 설명

프로젝트의 에셋을 찾아 선택하고 관리하는 에디터 창입니다.

## 비교와 선택

씬 계층을 표시하는 Hierarchy 창과 구분합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

Project 창의 의미를 설명하고 다음 조건을 구분해 주세요. 씬 계층을 표시하는 Hierarchy 창과 구분합니다.
