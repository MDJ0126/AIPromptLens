# Unity Accelerator

## 핵심 구조

Unity Accelerator → 기본 정의 → 적용 범위와 비교

## 개념 설명

팀이 가져온 에셋의 처리 결과를 캐시하여 재가져오기 부담을 줄이는 도구입니다.

## 비교와 선택

원본 파일을 관리하는 버전 관리 시스템을 대체하지 않습니다. 네트워크와 캐시 구성을 확인합니다.
