# 물리 재질

## 핵심 구조

표면 속성 → 접촉 결합 → 마찰과 반발

## 개념 설명

접촉의 마찰과 반발 성질을 정의합니다.

## 활용 상황

얼음·고무·바닥의 미끄러짐과 튀는 정도를 구분합니다.

## 비교와 선택

두 표면 속성을 결합하는 규칙도 결과에 영향을 줍니다. 먼저 목적에 맞는지 판단하고, 비용과 결과는 대상 환경에서 확인합니다.

## 설계할 때 확인

입력값과 처리 결과를 구분하고, 실패하거나 범위를 벗어나는 상황을 정합니다. 두 표면 속성을 결합하는 규칙도 결과에 영향을 줍니다.

## 도식의 한계

이 카드는 처리 단계 안내를 반복 재생합니다. 실제 Physics material의 화면 효과나 엔진 실행을 재현한 영상은 아닙니다.

## 요청 예시

물리 재질을 게임에 적용하려고 합니다. 접촉의 마찰과 반발 성질을 정의합니다. 사용 상황과 핵심 구조를 설명하고, 주요 설정값과 한계도 제안해 주세요.
