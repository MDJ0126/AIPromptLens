# 개발 빌드

## 핵심 구조

개발 빌드 → 기본 정의 → 적용 범위와 비교

## 개념 설명

디버깅과 성능 조사에 필요한 기능을 포함하도록 만드는 빌드입니다.

## 비교와 선택
