# 텍스처

## 핵심 구조

텍스처 → 기본 정의 → 적용 범위와 비교

## 개념 설명

표면이나 UI 등에 사용하는 이미지 또는 샘플링 데이터 자원입니다.

## 비교와 선택

색 정보만 담는 것은 아닙니다. 노멀·깊이 등 데이터 용도에 맞춰 색 공간과 포맷을 선택합니다.
