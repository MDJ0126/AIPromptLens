# 스프라이트 아틀라스

## 핵심 구조

스프라이트 아틀라스 → 기본 정의 → 적용 범위와 비교

## 개념 설명

여러 Sprite 이미지를 하나의 텍스처 묶음으로 배치하는 자원입니다.

## 비교와 선택

재질과 렌더 상태가 다르면 아틀라스만으로 드로 콜이 합쳐지지 않습니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

스프라이트 아틀라스의 의미를 설명하고 다음 조건을 구분해 주세요. 재질과 렌더 상태가 다르면 아틀라스만으로 드로 콜이 합쳐지지 않습니다.
