# 네이티브 플러그인

## 핵심 구조

네이티브 플러그인 → 기본 정의 → 적용 범위와 비교

## 개념 설명

C·C++ 등으로 만든 플랫폼별 라이브러리를 Unity에서 호출하는 구성입니다.

## 비교와 선택

CPU 아키텍처와 플랫폼별 라이브러리를 맞춰야 합니다. 관리 코드와의 데이터 전달 방식도 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.
