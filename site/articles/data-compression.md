# 데이터 압축

## 핵심 구조

데이터 압축 → 기본 정의 → 적용 범위와 비교

## 개념 설명

데이터 표현을 바꿔 저장이나 전송 비용을 줄이는 방법입니다.

## 비교와 선택

무손실과 손실 압축을 구분합니다. 크기 감소와 복원 비용·품질을 함께 고려합니다.

## 적용 범위
