# 레거시 조이스틱 번호

## 핵심 구조

레거시 조이스틱 번호 → 기본 정의 → 적용 범위와 비교

## 개념 설명

기존 Input Manager의 축이 읽을 조이스틱 대상을 선택하는 설정입니다.

## 비교와 선택

Input System의 기기 매칭 설정과 다릅니다. 기존 입력 체계에서 쓰는 속성입니다. 확인한 상세 자료는 Unity 2018.4입니다. Unity 6에서 같은 속성명이 유지되는지는 미확인입니다.

## 적용 범위

Unity 2018.4 (역사·레거시 자료)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

레거시 조이스틱 번호의 의미를 설명하고 다음 조건을 구분해 주세요. Input System의 기기 매칭 설정과 다릅니다. 기존 입력 체계에서 쓰는 속성입니다. 확인한 상세 자료는 Unity 2018.4입니다. Unity 6에서 같은 속성명이 유지되는지는 미확인입니다.
