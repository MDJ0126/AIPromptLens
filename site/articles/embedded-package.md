# 임베디드 패키지

## 핵심 구조

임베디드 패키지 → 기본 정의 → 적용 범위와 비교

## 개념 설명

프로젝트의 Packages 폴더 안에서 소스를 직접 관리하는 패키지입니다.

## 비교와 선택

캐시된 레지스트리 패키지와 구분합니다. 프로젝트 내 수정 내용을 버전 관리해야 합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

임베디드 패키지의 의미를 설명하고 다음 조건을 구분해 주세요. 캐시된 레지스트리 패키지와 구분합니다. 프로젝트 내 수정 내용을 버전 관리해야 합니다.
