# 모델 파일

## 핵심 구조

모델 파일 → 기본 정의 → 적용 범위와 비교

## 개념 설명

메시·뼈·애니메이션 등 3D 자원을 교환하고 가져오는 파일입니다.

## 비교와 선택

파일 형식별로 포함되는 데이터가 다릅니다. 임포트 설정과 원본 데이터의 단위를 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

모델 파일의 의미를 설명하고 다음 조건을 구분해 주세요. 파일 형식별로 포함되는 데이터가 다릅니다. 임포트 설정과 원본 데이터의 단위를 확인합니다.
