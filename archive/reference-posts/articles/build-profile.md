# 빌드 프로필

## 핵심 구조

빌드 프로필 → 기본 정의 → 적용 범위와 비교

## 개념 설명

플랫폼별 빌드를 만들 때 사용할 설정 묶음을 관리합니다.

## 비교와 선택

플랫폼 대상과 프로필의 설정 덮어쓰기를 구분합니다. Unity 6의 프로필 구조를 기준으로 설명합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

빌드 프로필의 의미를 설명하고 다음 조건을 구분해 주세요. 플랫폼 대상과 프로필의 설정 덮어쓰기를 구분합니다. Unity 6의 프로필 구조를 기준으로 설명합니다.
