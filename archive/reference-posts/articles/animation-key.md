# 애니메이션 키

## 핵심 구조

애니메이션 키 → 기본 정의 → 적용 범위와 비교

## 개념 설명

특정 시점의 애니메이션 속성 값을 기록한 데이터입니다.

## 비교와 선택

키 사이의 값은 곡선의 보간 규칙에 따라 결정됩니다. 모든 프레임에 키를 넣을 필요는 없습니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

애니메이션 키의 의미를 설명하고 다음 조건을 구분해 주세요. 키 사이의 값은 곡선의 보간 규칙에 따라 결정됩니다. 모든 프레임에 키를 넣을 필요는 없습니다.
