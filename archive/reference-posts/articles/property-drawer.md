# 프로퍼티 드로어

## 핵심 구조

프로퍼티 드로어 → 기본 정의 → 적용 범위와 비교

## 개념 설명

직렬화된 필드나 타입의 Inspector 표시 방식을 확장하는 에디터 기능입니다.

## 비교와 선택

필드 데이터 자체의 런타임 동작을 자동으로 바꾸는 기능이 아닙니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

프로퍼티 드로어의 의미를 설명하고 다음 조건을 구분해 주세요. 필드 데이터 자체의 런타임 동작을 자동으로 바꾸는 기능이 아닙니다.
