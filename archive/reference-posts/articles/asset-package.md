# 에셋 패키지

## 핵심 구조

에셋 패키지 → 기본 정의 → 적용 범위와 비교

## 개념 설명

Unity 에셋을 묶어 가져오기와 내보내기에 사용하는 .unitypackage 파일입니다.

## 비교와 선택

Package Manager의 UPM 패키지와 파일 구조 및 의존성 관리 방법이 다릅니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.
