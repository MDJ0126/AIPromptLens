# 멀티플레이 네트워킹

## 핵심 구조

멀티플레이 네트워킹 → 기본 정의 → 적용 범위와 비교

## 개념 설명

여러 참여자의 입력과 게임 상태를 네트워크로 주고받는 구성입니다.

## 비교와 선택

Unity 6에서는 선택한 패키지와 서비스에 따라 구현이 달라집니다. 하나의 내장 네트워크 API로 단정하지 않습니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

멀티플레이 네트워킹의 의미를 설명하고 다음 조건을 구분해 주세요. Unity 6에서는 선택한 패키지와 서비스에 따라 구현이 달라집니다. 하나의 내장 네트워크 API로 단정하지 않습니다.
