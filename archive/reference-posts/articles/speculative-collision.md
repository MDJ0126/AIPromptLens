# 추측 기반 연속 충돌 검출

## 핵심 구조

추측 기반 연속 충돌 검출 → 기본 정의 → 적용 범위와 비교

## 개념 설명

다음 이동을 고려해 넓힌 경계로 접촉 가능성을 예측하는 검출 방식입니다.

## 비교와 선택

스윕 기반 연속 검출과 다릅니다. 실제로 닿지 않은 형상에서 접촉처럼 반응하는 경우를 점검합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

추측 기반 연속 충돌 검출의 의미를 설명하고 다음 조건을 구분해 주세요. 스윕 기반 연속 검출과 다릅니다. 실제로 닿지 않은 형상에서 접촉처럼 반응하는 경우를 점검합니다.
