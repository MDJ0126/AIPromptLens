# Unity 플러그인

## 핵심 구조

Unity 플러그인 → 기본 정의 → 적용 범위와 비교

## 개념 설명

외부 코드 라이브러리로 Unity 기능을 확장하는 구성입니다.

## 비교와 선택

관리 코드와 네이티브 플러그인을 구분합니다. 라이브러리별 라이선스와 플랫폼 지원을 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.

## 요청 예시

Unity 플러그인의 의미를 설명하고 다음 조건을 구분해 주세요. 관리 코드와 네이티브 플러그인을 구분합니다. 라이브러리별 라이선스와 플랫폼 지원을 확인합니다.
