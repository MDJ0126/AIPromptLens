# 레이어 마스크

## 핵심 구조

레이어 마스크 → 기본 정의 → 적용 범위와 비교

## 개념 설명

Unity 레이어들을 포함하거나 제외할지 비트 값으로 표현합니다.

## 비교와 선택

레이어 번호와 마스크 값을 구분합니다. 렌더링·레이캐스트 등 API의 입력 형식을 확인합니다.
