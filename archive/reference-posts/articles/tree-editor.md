# Tree Editor

## 핵심 구조

Tree Editor → 기본 정의 → 적용 범위와 비교

## 개념 설명

Unity 에디터에서 가지와 잎을 구성해 수목을 제작하는 기존 도구입니다.

## 비교와 선택

Unity 6 문서는 Built-in 전용·이전 콘텐츠 호환용이라고 설명합니다. URP·HDRP는 다른 수목 제작 경로를 확인합니다.

## 적용 범위

Unity 6.0 (6000.0)을 참고한 설명입니다. 엔진마다 같은 이름이나 API를 제공한다고 가정하지 않습니다. 플랫폼·패키지·렌더 파이프라인 조건은 연결된 문서를 함께 확인하세요.
